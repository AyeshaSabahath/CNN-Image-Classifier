# Image Classification using Convolutional Neural Networks (CNN)

A modular, production-quality image classification project built with **TensorFlow / Keras**, featuring training, evaluation, CLI prediction, Grad-CAM explainability, webcam capture, and a polished **Streamlit** web app.

---

## Project Overview

This repository trains a Convolutional Neural Network to classify real-world images. You can switch between two datasets with a single configuration variable:

| Option | Dataset | Task | Input |
|--------|---------|------|-------|
| **A** | Cats vs Dogs | Binary classification | 128×128 RGB |
| **B** | Fashion-MNIST | 10-class classification | 28×28 grayscale |

Default dataset: **Fashion-MNIST** (downloads automatically via Keras — no Kaggle credentials required).

---

## Dataset

### Fashion-MNIST (default)

Loaded with `tensorflow.keras.datasets.fashion_mnist`.

Classes: T-shirt/top, Trouser, Pullover, Dress, Coat, Sandal, Shirt, Sneaker, Bag, Ankle boot.

### Cats vs Dogs

Based on the popular [Cat and Dog](https://www.kaggle.com/datasets/tongpython/cat-and-dog) style dataset. When selected, the project downloads the Microsoft Cats & Dogs archive, cleans corrupt files, and organizes images into:

```text
dataset/train/{cat,dog}
dataset/validation/{cat,dog}
dataset/test/{cat,dog}
```

### Switching datasets

Edit `utils.py`:

```python
DATASET_CHOICE = "fashion_mnist"  # or "cats_dogs"
```

Then retrain:

```bash
python train.py
```

## Training

```bash
python train.py
```

What this does:

1. Loads and preprocesses the selected dataset
2. Builds the CNN (Conv32 → Conv64 → Conv128 → Dense 256 → Dropout → Output)
3. Trains for **15 epochs**, batch size **32**
4. Saves the best model via `ModelCheckpoint` to `models/cnn_model.h5`
5. Applies `EarlyStopping` and `ReduceLROnPlateau`
6. Writes curves to:
   - `images/training_accuracy.png`
   - `images/training_loss.png`
7. Saves `models/training_metadata.json`

Optional data augmentation (rotation, zoom, flip, shear, brightness) is enabled by default.

## CNN Architecture

```text
Input
  ↓
Conv2D(32) → ReLU → MaxPooling
  ↓
Conv2D(64) → ReLU → MaxPooling
  ↓
Conv2D(128) → ReLU → MaxPooling
  ↓
Flatten
  ↓
Dense(256) → Dropout(0.5)
  ↓
Dense(output)   # Sigmoid (binary) or Softmax (multi-class)
```

- Optimizer: **Adam**
- Loss: **BinaryCrossentropy** or **SparseCategoricalCrossentropy**
- Metric: **Accuracy**
